
### Functions/Methods
1. **.lenght() or .size()** : returns the length of a string
2. **pow(num, power)** : returns the floating point value of num^power
    1.  Use round(pow(num, power)) : to remove the choping of floating point.
3. **round(float):** decimal of .5 or higher gets ceiling value, and lower value gets floor value
